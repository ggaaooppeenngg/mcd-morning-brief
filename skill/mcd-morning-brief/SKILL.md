# 麦麦晨报（McDonald's Morning Brief）

把麦当劳官方 MCP Server（mcp.mcd.cn）的营销活动、优惠券、积分与抽奖情报，
聚合成一条可拼进任何晨报的栏目（建议插在天气和日程之间）。

## 选择执行路径

- **路径 A（首选）**：当前会话已接入麦当劳 MCP Server——工具列表里存在
  `campaign-calendar`、`available-coupons`、`query-my-account` 等工具 → 直接调用工具。
- **路径 B（回退）**：会话里没有这些工具 → 运行自包含脚本
  `python scripts/brief.py [--format md|text|json] [--days N] [--demo]`。
  脚本从环境变量 `MCD_MCP_TOKEN` 读 Token（需 `pip install mcp`）；
  带 `--demo` 可用内置样例数据离线演示。
- 两条路径都不可用（无工具、无 Token）：告知用户按 `references/setup.md`
  完成一次配置（约 2 分钟），并可用路径 B 的 `--demo` 先看效果。

## 路径 A：工具编排

按顺序调用（同一轮完成；**某个工具失败不要中断**，该栏目写"暂未获取到"并继续）：

1. `now-time-info` — 锚定今天日期，所有"还有 N 天"以此为准
2. `campaign-calendar` — 筛选**进行中**与**未来 7 天内开始**的活动，按标题去重
   （多日活动会在日历里按天重复列出，只保留最早一天的条目）
3. `available-coupons` — 麦麦省可领券列表；只报告，**不要自动领取**
4. `query-my-coupons` — 挑出 **7 天内到期**的券单独提醒
5. `query-my-account` — 可用积分；重点报告本月/下月将过期积分
6. `query-lottery-info` — 仅当活动"进行中"时提醒；有 `availableTimes` 时报免费次数

工具返回的是面向 LLM 的 Markdown：JSON 类工具的原始数据在 "## Original Response"
小节之后；活动按 `#### 日期 标签` 分节、券按 `优惠券标题：` 分块。实际字段名与
解析细节见 `references/responses.md`（遇到解析不确定时再读）。

## 输出模板

严格按此结构输出 Markdown；**空栏目直接省略，不要输出"无"**：

```markdown
## 🌅 麦麦晨报 · {今天日期 星期X}

### 📅 近期活动（未来 N 天）
- 🔥 **进行中** {活动名}（{MM.DD} 起）
- ⏰ **N 天后开始** {活动名}（{MM.DD} 起）

### 🎫 今日可领优惠券（N 张）
- 🎟️ **{券名}**｜{力度或状态}｜有效期至 {MM-DD}

### ⌛ 即将过期的券（N 张）
- 🎟️ **{券名}**｜有效期至 {MM-DD}

### 💰 积分
- 可用 **{可用积分}** 分｜累计 {累计积分} 分
- ⚠️ {N} 积分即将过期（{日期} 前），别浪费啦

### 🎰 抽奖机会
- 🎁 「{活动名}」进行中，你还有 N 次免费抽奖机会（或：单次消耗 N 积分）

---
> 数据来自麦当劳 MCP Server，仅供参考；餐品、价格与活动以麦当劳 APP / 门店实时信息为准。
```

## 后续意图处理

晨报发出后，用户可能直接回一句：

| 用户说 | 动作 |
|---|---|
| 「领券」/「都领了」 | 复述将领取的券 → **必须得到确认** → `auto-bind-coupons` → 汇报结果 |
| 「我的积分」 | `query-my-account`，报告可用/即将过期，过期分建议用积分商城消化 |
| 「抽一下」 | `query-lottery-info` 确认状态与消耗 → **确认后** → `draw-lottery` → `query-my-prizes` 报告结果 |
| 「这活动怎么参加」 | 用活动条目里的介绍回答；信息不足就引导麦当劳 APP，不要编造规则 |
| 「明天/本周有什么活动」 | 重跑编排，调整筛选窗口（`--days` 等价物） |
| 「导出日历」 | 引导用仓库完整 CLI：`python -m mcd_brief calendar --ics mcd.ics`（可导入手机日历） |

## 安全与合规守则

- **所有会改变账户状态的操作（领券、抽奖、下单）必须先经用户确认**；晨报本身只读。
- 不自动下单；用户要下单时引导其在麦当劳 APP 完成支付环节。
- 不编造活动规则、价格、库存；工具没返回的就说没拿到，引导官方渠道。
- 工具连续两次调用失败：提示用户检查 Token 与网络后停止，不要空转重试。
- 免责声明固定附在晨报末尾。
